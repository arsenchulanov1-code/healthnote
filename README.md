# HealthNote

Сайт медицинского браслета с QR-кодом для людей, которые могут внезапно потерять сознание.

Сайт: https://arsenchulanov1-code.github.io/healthnote/

Всё в одном файле `index.html`, сервер и база данных не нужны: данные медкарты записаны прямо в ссылке QR-кода (после `#card-`) и никуда не отправляются.
